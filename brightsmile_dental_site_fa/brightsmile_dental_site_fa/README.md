# وب‌سایت کلینیک دندان‌پزشکی لبخند روشن

نمونه وب‌سایت فارسی و واکنش‌گرا با Flask و SQLite.

## اجرای محلی

۱. Python نسخه ۳.۱۰ یا جدیدتر نصب باشد.
۲. ترمینال را در پوشه پروژه باز کنید.
۳. وابستگی‌ها را نصب کنید:

```bash
python -m pip install -r requirements.txt
```

۴. برنامه را اجرا کنید:

```bash
python main.py
```

۵. نشانی http://127.0.0.1:5000 را در مرورگر باز کنید.

## صفحه‌ها

- `/` — صفحه اصلی
- `/services` — خدمات
- `/team` — تیم درمان
- `/appointments` — فرم درخواست نوبت

درخواست‌ها در فایل محلی `clinic.db` ذخیره می‌شوند.

## پیش از انتشار عمومی

این پروژه صرفاً نمونه آموزشی است و سامانه واقعی نوبت‌دهی پزشکی محسوب نمی‌شود. اطلاعات واقعی یا حساس بیماران را در آن جمع‌آوری نکنید. برای استفاده عمومی باید احراز هویت و کنترل دسترسی، تنظیمات امن، HTTPS، پشتیبان‌گیری، مقابله با هرزنامه و بررسی الزامات حریم خصوصی اضافه شود. اطلاعات نمونه را جایگزین کنید و حالت debug را در محیط انتشار خاموش کنید.
